# Experiment 007 — ARES: The Last Directive

An original cinematic AI leadership simulation set on Mars.

The complete prototype is divided into six focused routes: briefing, three connected chapters, mission result and facilitated leadership debrief. Decisions persist across pages for a final leadership index.

## Optional opening video

The opening uses the cinematic exterior image as its full-screen background.

Recommended format: 1920×1080, H.264 MP4, 10–25 seconds, ideally under 12 MB. Avoid embedding titles in the video because the page provides accessible live text.

Open `index.html` directly or run it through a local web server.
